# FOREX LIFE

Landing page and initial multi-user MT5 auto-trading dashboard foundation.

## Current
- Forex Life landing page
- Private access-key entry UI
- Custom analysis dashboard
- BUY / SELL / WAIT concept with no forced entries
- Auto Trade master switch
- Risk-control settings UI
- MT5 account/position placeholders

## Next production modules
- Secure server-side user authentication
- Broker/MT5 account connection
- Live OHLC/tick data
- Quantitative analysis engine (SMA/EMA/RSI/ATR/volatility)
- Signal and confirmation engine
- Risk manager
- MT5 execution worker
- Position manager for SL/TP/trailing/break-even
- Multi-user isolation and encrypted credentials
- Backtesting and audit logs

Do not treat placeholder account values as real trading data. Live trading must remain disabled until a verified MT5 execution service and risk controls are connected.
